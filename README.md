## About The Project

This is a modern, fully responsive **personal portfolio website** built with **React**, **TypeScript**, and **Tailwind CSS**. It features smooth 3D animations powered by Three.js and Framer Motion, showcasing my skills, projects, certifications, and contact details in an interactive and professional format — crafted to make a strong impression on recruiters and collaborators.

---

## Features

- **Interactive 3D Hero Section** — Immersive 3D animation using React Three Fiber and Three.js
- **Animated UI Transitions** — Smooth, polished animations throughout using Framer Motion
- **Projects Showcase** — Project cards with modal previews, tech stack, and GitHub links
- **Skills and Tech Stack** — Visual overview of all languages, frameworks, and tools
- **Certifications Section** — Dedicated showcase for all professional certifications
- **Downloadable Resume** — One-click resume download directly from the portfolio
- **Contact Form** — Integrated with Formspree for direct email communication
- **Fully Responsive** — Optimized for all screen sizes, mobile to desktop
- **Dark Modern Theme** — Sleek dark UI with gradient accents and glassmorphism effects

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn
- Git

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/karthi2006-46/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

> The app will be live at `http://localhost:5173`

### Build for Production

```bash
# Build the project
npm run build

# Preview the production build locally
npm run preview
```
